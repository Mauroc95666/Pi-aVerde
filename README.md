# PIÑAVERDE Web

Sitio estático listo para subir a Vercel.

## Archivos principales

- `index.html`: contenido de la página.
- `styles.css`: diseño visual y responsive.
- `script.js`: animaciones suaves y contadores.
- `assets/`: logo, etiqueta y proceso del proyecto.

## Subir a Vercel

1. Sube esta carpeta como proyecto.
2. En Vercel, usa configuración estática sin framework.
3. No hace falta comando de build.
4. El directorio de salida es la raíz del proyecto.
